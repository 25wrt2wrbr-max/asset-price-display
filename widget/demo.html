Trend Badge

Add one script tag to your site and get a three-month price line with a Bullish, Bearish or Neutral badge. You supply the prices. All prices on this page are made up for the demo.

1. Cards from your own price files

Point src at a JSON or CSV file on your own site.

<script src="trend-widget.js"></script>
<trend-badge name="Rising example" src="/prices/rising.json" currency="USD"></trend-badge>

2. A small badge inside text

Our tracked fund is currently while the sideways one reads . 
<trend-badge layout="badge" src="/prices/fund.json"></trend-badge>

3. Your own colours and font

trend-badge {
  --trend-up: #2563eb;  --trend-down: #b45309;  --trend-radius: 4px;
  --trend-font: Georgia, serif;
}

4. From JavaScript

Hand prices straight to the widget, and listen for the result.

const el = TrendWidget.mount("#js-slot", prices, { name: "From JavaScript", currency: "USD" });
el.addEventListener("trend", (e) => console.log(e.detail.words));

5. A file that will not load

A missing file is shown as missing. It is never shown as a Neutral reading.
