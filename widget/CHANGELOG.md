# Changelog

## 1.0.0

- First release: the `<trend-badge>` element, with a card layout and a small
  badge layout.
- Reads JSON, CSV, number lists and data passed in from JavaScript.
- Light and dark themes, CSS variables, `::part()` styling.
- A price readout when you hover over or touch the line.
- `TrendWidget.judge`, `TrendWidget.mount`, and the `trend` and `trenderror` events.
